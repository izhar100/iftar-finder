# 🌙 Iftar Finder

**Iftar Finder** is a simple web application that helps users find Iftar timings based on their location. The project is designed to make it easier to quickly check the daily Iftar time without manually searching through different sources.

🔗 **Live Demo:** https://iftarfinder.vercel.app/
🔗 **GitHub:** https://github.com/izhar100/iftar-finder

---

## ✨ Features

* 📍 Find Iftar timing based on location
* 🕌 Simple and focused Islamic utility
* 📱 Responsive design for mobile, tablet, and desktop
* ⚡ Fast and lightweight interface
* 🎨 Clean and modern UI
* 🌐 Accessible directly from the browser
* 🚀 Deployed on Vercel

---

## 🛠️ Tech Stack

* **Frontend:** React
* **JavaScript:** Modern JavaScript (ES6+)
* **Styling:** CSS
* **Deployment:** Vercel
* **Version Control:** Git & GitHub

---

## 📸 How It Works

1. Open **Iftar Finder**.
2. Provide or select your location.
3. The application determines the relevant Iftar timing.
4. View the timing directly in the interface.

The goal is to keep the experience simple so users can get the information they need quickly.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/)
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/izhar100/iftar-finder.git
```

Navigate to the project:

```bash
cd iftar-finder
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application should now be available at:

```text
http://localhost:3000
```
